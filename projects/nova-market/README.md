# Nova Market — Five-page e-commerce storefront

A responsive e-commerce portfolio demonstration by Alpha Tech Hub, built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home / featured products
- `shop.html` — Product catalogue, search and category filters
- `about.html` — Store story and values
- `contact.html` — Contact information and demo form
- `cart.html` — Shopping bag, quantity controls and order summary

## Features
- Shared navigation and responsive layout
- Product catalogue in Nigerian Naira (NGN)
- Search and category filtering
- Add-to-cart, quantity updates and item removal
- Shopping bag persists with localStorage across pages
- Demo checkout and contact form; neither transmits data or accepts payments

## Live demo
https://abdulbasit-2020.github.io/Alpha-Tech-Hub/projects/nova-market/

This is a frontend portfolio demo. A production store needs a secure backend, order management, inventory, customer authentication and payment-provider integration.
