# Nova Market — Responsive five-page storefront

Responsive e-commerce portfolio demo by Alpha Tech Hub, built with HTML, CSS and vanilla JavaScript.

Pages: Home, Shop, About, Contact and Shopping Bag.

Improvements: rebuilt responsive layouts for phones/tablets/desktops; consistent design tokens and spacing; compact mobile navigation; responsive product cards and cart; accessible focus states; reduced-motion support; defensive localStorage parsing and cart validation; persistent cart across pages; image fallbacks; improved empty states; NGN formatting.

This is a frontend demo. Contact messages are not transmitted and checkout does not process payments. A production store requires secure backend services, authentication, inventory/order management and payment integration.

Live demo: https://abdulbasit-2020.github.io/Alpha-Tech-Hub/projects/nova-market/
