# NovaPay — Fintech App Demo

A 10-page responsive fintech dashboard concept built for the Alpha Tech Hub portfolio.

## Pages
1. Overview dashboard (`index.html`)
2. Accounts (`accounts.html`)
3. Transfers (`transfers.html`)
4. Cards (`cards.html`)
5. Payments (`payments.html`)
6. Savings (`savings.html`)
7. Investments (`investments.html`)
8. Transactions (`transactions.html`)
9. Profile (`profile.html`)
10. Help & Support (`support.html`)

## Features
- Responsive sidebar navigation and mobile menu
- Dashboard canvas chart and spending summary
- Demo transfer review, card freeze toggle, payment dialogs
- Savings goals saved to browser localStorage
- Transaction search and category filters
- Profile preferences saved locally and FAQ support page
- Remote Unsplash photography and Google Fonts

## Important prototype notice
NovaPay is a fictional portfolio project, not a bank or licensed financial service. All balances and transactions are sample data. Transfers and bill payments are simulations only; no real funds move. No payment gateway, banking API, authentication, KYC, or backend is connected. Never enter real banking credentials or sensitive personal information.

## Run
Open `index.html` through a local web server or deploy the folder to GitHub Pages. Internet access is required for remote photos and fonts.
